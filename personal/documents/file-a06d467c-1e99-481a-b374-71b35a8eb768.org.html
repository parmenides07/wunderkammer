k nearest neighbor

  • This is incredibely simple algorithm. Essentially it goes off of the hypothesis that if a test data point is close to an actual data point input then the test output will likely be similar to the others output.
  • k nearest neighbor just says find the k amouhnt of nearest neighbors (real data inputs) given the test input and then average the k nearest inputs' output
