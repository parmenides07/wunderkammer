- I'm striving for a look that is timeless, non-alienating, and non-minamalist. I want anyone to be able to use this program and not be thrown off by the visuals. This would be easily achievable by making it a minamalist traditional software. However I want it to be beautiful and with visceral visuals, the software should burst with color and motion. It should feel *alive*. 
- I think the solution to this is having customizable visuals. Both manual and emergent visual development.
